# Gear Stats

Stats of every weapon, piece of apparel and turret on the map in one sortable table: damage, DPS, accuracy, range, armor, value, quality.

## What it does

- A "gear" main tab opens a table split into ranged, melee, grenades, other, apparel, tools and turrets.
- Sort by any column; filter by location (ground, storage, corpses) and owner (colonists, friendlies, hostiles, prisoners, craftable).
- Modded gear is picked up automatically; Combat Extended columns appear when CE is active; Weapon Storage and Change Dresser containers are included when present.
